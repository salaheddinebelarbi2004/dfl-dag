# ============================================================
# TROUBLESHOOTING
# ============================================================

# Problem: "No client files found"
# Solution: Make sure real_federated_data/ folder exists with client_*.npz files

# Problem: "ModuleNotFoundError: numpy"
# Solution: pip install -r requirements.txt

# Problem: Nodes won't connect
# Solution: Make sure port 5000, 5001, 5002 are free
# Check: netstat -ano | findstr :5000 (Windows)

# Problem: Out of memory
# Solution: Reduce NUM_CLIENTS or BATCH_SIZE in config

# Problem: Training is too slow
# Solution: Reduce LOCAL_EPOCHS or NUM_ROUNDS
